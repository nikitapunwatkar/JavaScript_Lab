3. Theory

3.1 Overview

A billing calculator is a web application that computes the total bill amount for products including taxes (GST - Goods and Services Tax). This experiment demonstrates fundamental JavaScript concepts including variables, user input handling, arithmetic operations, object manipulation, destructuring, and dynamic HTML generation.

3.2 Key Concepts

3.2.1 Variables and Data Types

Definition: Variables store data values that can be used and manipulated throughout the program.
Types Used:
  • String: Text data (Customer Name, Product Name)
  • Number: Numerical values (Quantity, Price, Total)
  • Constant: Fixed values (GST rate = 0.18)

3.2.2 GST Calculation (Goods and Services Tax)

GST is an indirect tax applicable in India and many other countries. In this application:

  • GST Rate: 18% (defined as constant 0.18)
  • Formula: GST Amount = Total Amount × GST Rate
  • Final Bill: Final Bill = Total Amount + GST Amount
Example Calculation:
If Quantity = 5, Price = 100
Total = 5 × 100 = ₹500
GST = 500 × 0.18 = ₹90
Final Bill = 500 + 90 = ₹590

3.2.3 User Input with prompt()

The prompt() function displays a dialog box to collect user input. The syntax is:

var variable = prompt("Enter a value");

It returns a string, which is converted to a number using the Number() constructor for numerical operations.

3.2.4 Input Validation

Input validation ensures data integrity by checking:

if (isNaN(quantity) || quantity < 0) quantity = 0;
if (isNaN(price) || price < 0) price = 0;
  • isNaN() - Checks if a value is Not a Number
  • Negative value check - Prevents invalid negative prices/quantities
  • Default value - Sets invalid inputs to 0

3.2.5 JavaScript Objects

Objects are collections of key-value pairs used to store related data:

const bill = {
    customer: customerName,
    product: productName,
    quantity: quantity,
    price: price,
    total: total,
    gstAmount: gstAmount,
    finalBill: finalBill
};

3.2.6 Object Destructuring

Destructuring extracts specific properties from an object and assigns them to new variables:

const {
    customer,
    product,
    gstAmount: gst,
    finalBill: amount
} = bill;

This creates new variables from object properties. Notice gstAmount: gst renames the property during extraction.

3.2.7 Template Literals

Template literals (backtick strings) allow embedding expressions using ${expression} syntax:

document.write(`<p>Customer: ${customer}</p>`);
document.write(`<p>Final Bill: ₹${amount.toFixed(2)}</p>`);

3.2.8 Number Formatting with toFixed()

The toFixed(n) method formats numbers to n decimal places:

${price.toFixed(2)} // Displays: ₹100.50
${gst.toFixed(2)} // Displays: ₹90.00

3.2.9 Dynamic HTML Generation

The document.write() method generates HTML content dynamically:

document.write(`<h3>Billing Receipt</h3>`);

3.3 Algorithm Flow

  1. Define GST constant (18%)
  2. Collect customer name via prompt
  3. Collect product name via prompt
  4. Collect quantity and validate input
  5. Collect price and validate input
  6. Calculate total = quantity × price
  7. Calculate GST amount = total × 0.18
  8. Calculate final bill = total + GST amount
  9. Create billing object with all values
  10. Extract required values using destructuring
  11. Generate and display formatted billing receipt

  • ✓ Input validation prevents errors
  • ✓ Object organization keeps data structured
  • ✓ Destructuring improves code readability
  • ✓ Template literals make output generation clean
  • ✓ Accurate decimal formatting for currency
